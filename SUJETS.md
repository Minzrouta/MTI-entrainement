# Planning des sujets — la source de vérité

**Règles** : publication **lundi-vendredi** uniquement. Les **lundis sont réservés à l'actu**
du développement (IA ou autre), rédigée chaque weekend avec Baptiste. Les sujets généraux
occupent mardi → vendredi. **Fin du programme : vendredi 30 octobre.** À partir de début
novembre : plus de nouveaux sujets, place aux **rappels de révision** (quiz croisés,
synthèses par catégorie) — tous les sujets intéressants auront été traités.

Les sujets trop proches ont été fusionnés pour que rien ne manque (noté « + » dans les titres).
Fusions notables : Node.js → event loop JS · clean archi → SOLID · webhooks → API design ·
caching HTTP → web perf · a11y → CSS · normalisation → index SQL · injections → OWASP ·
serverless/nginx → scaler une app · feature flags → déjà couvert par CI/CD · prompt
engineering → agents · hallucinations → LLM en prod.
